# bank account system

proyecto en python para simular un sistema simple de gestión de cuentas bancarias utilizando programación orientada a objetos.

## sobre el proyecto

el objetivo es implementar un sistema básico para crear y administrar cuentas bancarias, permitiendo realizar operaciones como depósitos, retiros y consultas de saldo.

también se incorporó una cuenta de ahorro con una tasa de interés y un administrador para gestionar diferentes cuentas.

## funcionalidades

el proyecto incluye:

* creación y gestión de cuentas
* depósitos y retiros
* validación de operaciones
* cuenta de ahorro con tasa de interés
* saldo mínimo para cuentas de ahorro
* búsqueda de cuentas por número
* eliminación de cuentas
* cálculo del saldo total
* pruebas automáticas

## conceptos de programación

se aplicaron diferentes conceptos de programación orientada a objetos:

* clases y objetos
* encapsulamiento
* herencia
* polimorfismo
* métodos de clase
* properties
* métodos mágicos
* manejo de excepciones

también se incorporaron pruebas automáticas utilizando `pytest`.
